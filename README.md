# RoboSense: Bluetooth Controlled RC Car & IoT Gas Monitoring System

**RoboSense** ek dual-purpose robotic project hai jo Arduino Uno, ESP32 aur 6 MQ-series gas sensors par aadharit hai[cite: 5].

## Main Features
- **RC Car Mode:** Bluetooth (HC-05) aur Arduino Uno se wireless movement control[cite: 5].
- **IoT Monitoring:** ESP32 aur Blynk Cloud par 6 gas sensors (MQ-2, MQ-3, MQ-4, MQ-7, MQ-8, MQ-9) ki real-time monitoring[cite: 5].
- **Alert System:** Gas level high hone par LED warning aur Blynk push notification[cite: 5].

## Hardware Stack
- Microcontrollers: Arduino Uno, ESP32 Dev Board[cite: 5]
- Motor Driver: L293D Shield + 4 BO Motors[cite: 5]
- Sensors: MQ-2, MQ-3, MQ-4, MQ-7, MQ-8, MQ-9[cite: 5]
