# RoboSense: Bluetooth Controlled RC Car & IoT Gas Monitoring System

**RoboSense** is a dual-purpose robotic project based on the Arduino Uno, ESP32, and six MQ-series gas sensors[cite: 5].

## Main Features
- **RC Car Mode:** Wireless movement control using a Bluetooth (HC-05) module and Arduino Uno[cite: 5].
- **IoT Monitoring:** Real-time monitoring of 6 gas sensors (MQ-2, MQ-3, MQ-4, MQ-7, MQ-8, MQ-9) using an ESP32 and the Blynk Cloud[cite: 5].
- **Alert System:** LED warnings and Blynk push notifications when gas levels are high[cite: 5].

## Hardware Stack
- Microcontrollers: Arduino Uno, ESP32 Dev Board[cite: 5]
- Motor Driver: L293D Shield + 4 BO Motors[cite: 5]
- Sensors: MQ-2, MQ-3, MQ-4, MQ-7, MQ-8, MQ-9[cite: 5]
